The prescription for the stellar oblateness and effective surface gravity is now chosen with the ``name`` argument of ``Star`` instead of the ``star_shape`` argument of ``Spacetime``, which was removed. Scripts that pass ``star_shape`` to ``Spacetime`` need to be updated. The options are ``'universal'`` (AlGendy & Morsink 2014; the default, also available with the old name ``'AGM_14'``), ``'sphere'``, ``'psr j1231-1411'`` and ``'psr j1614-2230'``. The function ``effective_gravity`` now takes the integer index ``obl_surfgrav_ind`` (see ``Spacetime.obl_surfgrav_ind``) instead of the string ``star_shape``, so custom priors that call it need to be updated.

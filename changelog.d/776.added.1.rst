New plot class ``ResidualStructurePlot`` in ``xpsi.PostProcessing``, which tests whether the standardised 2D residuals contain structure or are consistent with random noise, using six complementary tests (2D power spectrum, variogram, 2D autocorrelation scan, Kolmogorov-Smirnov + Ljung-Box, Moran's I and runs test). It prints a summary with a combined verdict (``STRUCTURED``, ``RANDOM`` or ``INCONCLUSIVE``), stores the results in ``residual_structure_results`` and ``residual_structure_verdict``, and plots tests 1 to 4 with a summary of all tests. It can be passed together with ``ResidualPlot`` for the same posterior, e.g. ``plots = {'ST': [ResidualPlot(plot_clusters=True), ResidualStructurePlot()]}``, in which case the model is evaluated only once. Moran's I requires the optional ``esda`` and ``libpysal`` packages, and the Ljung-Box test the optional ``statsmodels`` package.

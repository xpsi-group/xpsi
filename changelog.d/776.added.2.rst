``ResidualPlot`` (with ``plot_clusters=True``) now compares the cluster sizes with the range expected from counting noise alone, computed from Poisson realisations of the posterior-expected counts (new arguments ``cluster_null_n`` and ``cluster_null_random_seed``), and gives the p-value of the largest cluster (stored in ``cluster_max_size`` and ``cluster_max_pvalue``). The new ``cluster_connectivity`` argument sets whether pixels touching at a corner belong to the same cluster (``8``, default) or only pixels sharing an edge (``4``).

X-PSI now supports numpy 2.x. For example, uses of ``numpy.infty``, which was removed in numpy 2.0, were replaced by ``numpy.inf``; log-likelihood values are now always returned as numbers instead of one-element arrays; and the post-processing colormaps now use ``matplotlib.pyplot.get_cmap`` instead of ``matplotlib.cm.get_cmap``, which was removed in the matplotlib versions that support numpy 2.

Added a policy on the use of generative AI in contributions (:ref:`ai_policy`). Every pull request must now include an AI disclosure stating which tools, models and versions were used, if any; contributions opened by automated agents are not accepted; and AI assistance is recorded with an ``Assisted-by:`` commit trailer rather than by listing AI tools as co-authors. A new GitHub Actions check flags pull request commits that list an AI tool as co-author or author, and explains how to fix them.

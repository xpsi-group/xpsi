Added an optional ``short_labels`` dictionary argument to ``Runs.load_runs`` (stored alongside ``labels``) to set shorter parameter labels, e.g., without units. These are used to annotate the off-diagonal 2D panels of corner plots when ``labels_2D=True`` in ``CornerPlotter.plot``, so that the annotations fit within the panels. Parameters without a short label default to their full label from ``labels``, and a message lists them when ``labels_2D=True``.

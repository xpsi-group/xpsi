Added a documentation page, "Neutron star space-time models", to the User Guide. It describes the Oblate Schwarzschild plus Doppler approximation used for pulse-profile computation (including the comoving-area Lorentz factor and how the code combines it with the Doppler factors), the quasi-Kerr image-plane ray tracing used for imaging and sky maps, the oblateness and surface-gravity options of ``Star(name=...)``, and the papers and equations that each part of the code is based on. The ray-tracing, mesh and integrator source files now carry comments linking each step to these equations, and several docstrings (``Spacetime.zeta``, ``Spacetime.epsilon``, ``Spacetime.a``, ``compute_rays`` and the effective-gravity functions) were corrected or expanded.
